# Codex Quota Widget v1.0.0

First public release of Codex Quota Widget.

## Highlights

- Displays remaining Codex 5-hour and weekly quota
- Shows reset countdowns and refreshes every 60 seconds
- Borderless, draggable, slightly transparent, and always on top
- Uses the existing local Codex sign-in; no API key required
- Native Windows executable with no third-party runtime dependencies

Download `CodexQuotaWidget.exe` below and run it directly. Windows SmartScreen may show a warning because the executable is not code-signed.
